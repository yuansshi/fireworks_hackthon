# Video script (narration, ~2 min)

Generated by `scripts/make_media.py`; voice: macOS `say -v Samantha`.

**Slide 1 (0–7 s).** This is PhishGuard: an NVIDIA Nemotron model, fine-tuned on Fireworks, that catches scams across every channel.

**Slide 2 (7–21 s).** The problem: fraud teams must screen every email, text, link and phone call before customers act. Frontier models are accurate, but at sixteen hundred dollars per million messages, they are too expensive to run on everything.

**Slide 3 (21–38 s).** Our stack: Fireworks Serverless Training fine-tuned a hundred-and-twenty-billion-parameter Nemotron with LoRA in eleven minutes for about two dollars, with no GPUs, uploads or deployment. Fireworks inference gave us frontier baselines through one API, and Hugging Face supplied the data.

**Slide 4 (38–46 s).** We froze one evaluation: twenty-four hundred training examples and six hundred held-out cases, scored identically for every system.

**Slide 5 (46–56 s).** Here it is in action on held-out messages: our verdicts next to live Kimi K3 calls, with the cost per million messages on each line. Both miss one tricky URL.

**Slide 6 (56–66 s).** And the code. Training is a short loop: create a LoRA client, put the loss only on the answer tokens, then step and save a checkpoint we can sample directly.

**Slide 7 (66–75 s).** Each message gets cheap metadata and timing cues, like urgency words and suspicious links, and every model is scored on the same cases with a paired test.

**Slide 8 (75–89 s).** Now the key result. Before fine-tuning, Nemotron scored ninety point seven percent. After fine-tuning, ninety-seven point eight. Errors fell from fifty-six to thirteen, and false alarms on phone calls dropped from thirty-four percent to two.

**Slide 9 (89–103 s).** That also beats the frontier: thirteen errors versus twenty-three for Kimi K3, significant at p equals point zero four, at one seventh of the cost. The tradeoff: Kimi generalizes better to newer, unseen data.

**Slide 10 (103–110 s).** PhishGuard: frontier-beating accuracy from an open NVIDIA model you can run yourself. The code and evidence are in our repo.
